# Users administration — v1.0.45

Publish this branch’s complete `firestore.rules` before deploying. Existing payment administrators gain access to registered user profiles and the per-user administrator status required to display correct exemptions. Ordinary users and report reviewers do not gain this access. No new role or manual collection setup is needed if `paymentAdmins/{uid}.active` is already true.

Account → Administration → Users shows 25 Firestore user profiles per page, with display name, email, UID, profile creation time, trial end, approved subscription end and current status. Next page and exact-email search are supported without composite indexes. Authentication-only records without a Firestore profile are not listed. Manage offers app-access suspension/reactivation, separate sample-only and full-access grants, restored automatic subscription/trial access, and private inbox messages. It does not edit credentials, delete accounts, grant subscriptions or disable Firebase Authentication logins. A clearly labelled Firebase console link is provided for the last action. Financial administrator accounts cannot be changed here.

Status is based on the saved profile’s creation date. The current user’s reader additionally considers Firebase Auth creation metadata; an inconsistent legacy profile can therefore need investigation. Financial administrators are shown as exempt. Each page reads subscriptions and administrator status for the displayed profiles.

FAQ and user guide now cover current trials, manual payments, administrator setup, result sync, backups and offline access; outdated promises of unlimited free access and header trash-button repair have been removed. The current public EPUB is reduced to sample chapters and sample explanations; the full EPUB and premium practice sets are served from access-controlled Firestore documents.


Account management uses owner-readable `accountControls/{uid}` documents, writable only by payment administrators for non-administrator targets. Controls take effect in connected app sessions through a live listener. Previously cached offline access cannot receive a suspension until reconnecting. Previously published public releases and repository history may still contain the former full EPUB; this change cannot recall copies already downloaded or publicly cached. Trial-only mode ignores a paid expiry but preserves payment records. Reactivation preserves access mode; use Restore subscription access separately when needed.

Private messages use `users/{uid}/adminMessages`, are visible only in that account’s inbox, and are removed during account deletion. The owner must confirm sending; no messages are sent as part of setup or testing. App suspension still allows account settings, payments, backups and inbox access. Disabling sign-in itself is managed through the Firebase console.


## v1.0.51: sample access and protected full library
Free and three-day sample-trial accounts can read only the 2020/DD, AD I and AD II sample exams, their Sections A/B/C where present, and their linked explanations. Sample access continues after the trial ends. Active subscriptions, payment/report administrators and explicit full-access grants unlock the complete book and all practice sets. Ordinary free accounts are sample-only. Existing administrator-issued `free` control records retain full access as legacy grants; new grants use `full-access`. Suspension still overrides non-administrator access. Publish the matching `firestore.rules` before deploying the app, then use Account → Administration → Manage protected library to upload the ignored local source files once.
